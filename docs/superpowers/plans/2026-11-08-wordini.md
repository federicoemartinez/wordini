# Wordini: plan de implementación

> **Para agentes que lo ejecuten:** SUB-SKILL REQUERIDA: usar superpowers:subagent-driven-development (recomendado) o superpowers:executing-plans para implementar este plan tarea por tarea. Los pasos usan casillas (`- [ ]`) para el seguimiento.

**Objetivo:** construir Wordini, un puzzle diario de palabras con una cerradura tipo criptex (5 anillos de 10 letras; hay que alinear 3 palabras). Funciona en español, inglés y francés y es un sitio 100% estático.

**Arquitectura:**
- Un script de Python, que se corre una sola vez por idioma, genera `words/{lang}.json` a partir de `wordfreq`, Hunspell y una lista de bloqueo.
- En el navegador, `js/puzzle.js` genera el puzzle del día de forma determinista (semilla = idioma + día) y garantiza que la solución sea única.
- La interfaz es HTML, CSS y JS con módulos ES nativos, sin framework ni build.
- El estado se guarda en `localStorage`.

**Stack:**
- Sitio: HTML, CSS, JS (ES2022, módulos nativos).
- Tests: `node --test` (Node ≥ 22; probado con v24.13.0).
- Datos: Python 3.12 + `wordfreq` 3.1.1, solo para generarlos.
- Confetti: `canvas-confetti` 1.9.4 desde jsDelivr.
- Fuente: Bungee, desde Google Fonts.

**Spec:** `docs/superpowers/specs/2026-11-08-wordini-design.md`. Leerla antes de empezar; este plan la implementa.

**Estado del código:** todo el código de este plan ya se ejecutó en un prototipo:
- los 20 tests pasan en unos 5 s;
- se sacaron capturas con Chromium headless a 390 px y 320 px, en partida, con anillos trabados, con victoria y con error de carga.

Copiarlo tal cual. Si algo no anda, es una diferencia de entorno, no un error del plan.

## Restricciones globales

- **Dependencias:**
  - sin bundler, sin build y sin dependencias npm;
  - `package.json` solo declara `"type": "module"` y `"test": "node --test"`;
  - `wordfreq` vive solo en `tools/.venv/` (en `.gitignore`), igual que las fuentes descargadas en `tools/sources/`.
- **Constantes del juego:** `RING = 10` letras por anillo, `COLS = 5` anillos, `ROWS = 3` filas en la ventana, `MAX_ATTEMPTS = 6`.
- **Idiomas:** `es` (alfabeto `ABCDEFGHIJKLMNÑOPQRSTUVWXYZ`), `en` y `fr` (`ABCDEFGHIJKLMNOPQRSTUVWXYZ`).
- **Listas:** `valid` = palabras de 5 letras entre las 200.000 más frecuentes de `wordfreq`. `answers` = las 1.200 más frecuentes entre las raíces en minúscula de Hunspell que no están bloqueadas.
- **Azar:** `js/puzzle.js` nunca usa `Math.random`. Todo el azar sale de `` mulberry32(fnv1a(`${lang}:${day}`)) ``.
- **Solución oculta:** la solución nunca aparece en el DOM, en `localStorage` ni en una variable global. Vive en el closure de `createPuzzle`.
- **Paleta:** `--bg #0b0b14`, `--cyan #00e5ff`, `--magenta #ff2bd6`, `--green #39ff88`, `--dim #3a3a55`. Fuente Bungee.
- **Ancho:** mínimo 320 px y máximo 480 px de contenido.
- **Textos de la interfaz:** solo a través de `js/i18n.js`.
- **`prefers-reduced-motion: reduce`:** sin confetti, sin rebote y sin animación de la derrota.
- **Commits:** en español, con prefijos `feat:`, `test:`, `docs:` o `chore:`.

## Foco de revisión

Estos casos no los cubre ningún test automático y son los que más probablemente le fallen a un jugador. Cada uno tiene una verificación en la Tarea 6.

1. **El archivo de palabras no carga** (offline, 404), incluso al cambiar de idioma. Se ve un mensaje de error y nunca se guarda la partida de un idioma con la clave de otro.
2. **La pestaña sigue abierta después de medianoche.** Al volver a la pestaña se carga el puzzle nuevo.
3. **Recursos externos bloqueados** (jsDelivr, Google Fonts o `AudioContext`). El juego sigue jugable de principio a fin, solo sin confetti, sin la fuente o sin sonido.
4. **Pantalla de 320 px.** Los 5 anillos, la ventana y el encabezado entran sin scroll horizontal.
5. **Juego solo con teclado.** Se puede jugar con Tab, flechas y Enter. Enter sobre un botón enfocado no cuenta dos intentos.

```python
#!/usr/bin/env python3
"""Genera words/{lang}.json desde wordfreq + Hunspell (LibreOffice) + lista de bloqueo.

Uso: tools/.venv/bin/python tools/build_words.py es en fr
"""
import json
import re
import sys
import unicodedata
import urllib.request
from pathlib import Path

import wordfreq

ROOT = Path(__file__).resolve().parent.parent
SOURCES = ROOT / 'tools' / 'sources'
LIBRE = 'https://raw.githubusercontent.com/LibreOffice/dictionaries/master/'
LANGS = {
    'es': ('ABCDEFGHIJKLMNÑOPQRSTUVWXYZ', 'es/es_ES.dic'),
    'en': ('ABCDEFGHIJKLMNOPQRSTUVWXYZ', 'en/en_US.dic'),
    'fr': ('ABCDEFGHIJKLMNOPQRSTUVWXYZ', 'fr_FR/dictionaries/fr.dic'),
}
TOP_VALID = 200_000
N_ANSWERS = 1200


def normalize(word, lang):
    word = word.lower()
    if lang == 'es':
        word = word.replace('ñ', '\0')
    word = ''.join(c for c in unicodedata.normalize('NFD', word) if not unicodedata.combining(c))
    return word.replace('\0', 'ñ').upper()


def dic_text(path):
    local = SOURCES / Path(path).name
    if not local.exists():
        SOURCES.mkdir(parents=True, exist_ok=True)
        urllib.request.urlretrieve(LIBRE + path, local)
    return local.read_text(encoding='utf-8')


def build(lang):
    alphabet, dic = LANGS[lang]
    ok = lambda w: len(w) == 5 and all(c in alphabet for c in w)

    rank = {}  # palabra normalizada -> mejor posición en wordfreq
    for i, w in enumerate(wordfreq.top_n_list(lang, TOP_VALID)):
        n = normalize(w, lang)
        if ok(n):
            rank.setdefault(n, i)

    stems = set()  # raíces en minúscula del .dic: sin nombres propios ni flexiones
    for line in dic_text(dic).splitlines()[1:]:
        stem = re.split(r'[/\s]', line.strip(), maxsplit=1)[0]
        if stem[:1].islower():
            n = normalize(stem, lang)
            if ok(n):
                stems.add(n)

    blocklist = (ROOT / 'tools' / 'blocklist' / f'{lang}.txt').read_text(encoding='utf-8')
    blocked = {normalize(l.strip(), lang) for l in blocklist.splitlines() if l.strip()}

    candidates = [w for w in stems if w in rank and w not in blocked]
    answers = sorted(sorted(candidates, key=rank.get)[:N_ANSWERS])
    valid = sorted(rank)

    assert all(ok(w) for w in valid), 'palabra inválida en valid'
    assert set(answers) <= set(valid), 'answers no está incluido en valid'
    assert not set(answers) & blocked, 'palabra bloqueada en answers'
    assert len(answers) >= 500, f'muy pocas respuestas: {len(answers)}'

    out = ROOT / 'words' / f'{lang}.json'
    out.parent.mkdir(exist_ok=True)
    data = {'alphabet': alphabet, 'answers': answers, 'valid': valid}
    out.write_text(json.dumps(data, ensure_ascii=False, separators=(',', ':')), encoding='utf-8')
    print(f'{lang}: {len(valid)} válidas, {len(answers)} respuestas -> {out.relative_to(ROOT)}')


if __name__ == '__main__':
    langs = sys.argv[1:]
    assert langs and all(l in LANGS for l in langs), f'uso: build_words.py {" ".join(LANGS)}'
    for lang in langs:
        build(lang)
```

```js
// Puzzle diario determinista: misma (idioma, día) => mismo puzzle en cualquier navegador. Spec §4.
export const LAUNCH_DATE = [2026, 10, 9]; // año, mes 0-11, día: fecha del primer deploy público
export const RING = 10;
export const COLS = 5;
export const ROWS = 3;

// Días desde el lanzamiento según la fecha local. Date.UTC evita los días de 23/25 h por cambio de horario.
export function dayNumber(date = new Date()) {
  const local = Date.UTC(date.getFullYear(), date.getMonth(), date.getDate());
  return Math.max(0, (local - Date.UTC(...LAUNCH_DATE)) / 86400000);
}
```

```js

function fnv1a(str) {
  let h = 0x811c9dc5;
  for (let i = 0; i < str.length; i++) h = Math.imul(h ^ str.charCodeAt(i), 0x01000193);
  return h >>> 0;
}

function mulberry32(a) {
  return () => {
    a = (a + 0x6d2b79f5) | 0;
    let t = Math.imul(a ^ (a >>> 15), 1 | a);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

// Prefijos de valid (las palabras completas también son prefijos) y pesos de letras, una vez por lista.
const prepared = new WeakMap();
function prepare(words) {
  if (prepared.has(words)) return prepared.get(words);
  const prefixes = new Set();
  const counts = {};
  for (const w of words.valid) {
    for (let k = 1; k <= w.length; k++) prefixes.add(w.slice(0, k));
    for (const c of w) counts[c] = (counts[c] ?? 0) + 1;
  }
  const letters = [...words.alphabet].filter(c => counts[c]);
  let total = 0;
  const cumulative = letters.map(c => (total += counts[c]));
  const d = { prefixes, letters, cumulative, total };
  prepared.set(words, d);
  return d;
}

function weightedLetter(rand, d) {
  const x = rand() * d.total;
  return d.letters[d.cumulative.findIndex(c => x < c)];
}

// Cuenta combinaciones de offsets cuyas 3 filas son palabras válidas, columna por columna con poda.
// Corta en 2: solo importa si hay exactamente una.
function countSolutions(rings, prefixes) {
  const walk = (col, rows) => {
    if (col === COLS) return 1;
    let n = 0;
    for (let o = 0; o < RING && n < 2; o++) {
      const next = rows.map((r, k) => r + rings[col][(o + k) % RING]);
      if (next.every(p => prefixes.has(p))) n += walk(col + 1, next);
    }
    return n;
  };
  return walk(0, Array(ROWS).fill(''));
}

export function createPuzzle(lang, day, words) {
  const rand = mulberry32(fnv1a(`${lang}:${day}`));
  const d = prepare(words);
  for (let tries = 0; tries < 200; tries++) {
    const chosen = [];
    while (chosen.length < ROWS) {
      const w = words.answers[Math.floor(rand() * words.answers.length)];
      if (!chosen.includes(w)) chosen.push(w);
    }
    for (let fill = 0; fill < 20; fill++) {
      const rings = [];
      const solution = [];
      for (let i = 0; i < COLS; i++) {
        const p = Math.floor(rand() * RING);
        const ring = Array.from({ length: RING }, () => weightedLetter(rand, d));
        chosen.forEach((w, k) => (ring[(p + k) % RING] = w[i]));
        rings.push(ring);
        solution.push(p);
      }
      if (countSolutions(rings, d.prefixes) !== 1) continue;
      const start = solution.map(s => (s + 1 + Math.floor(rand() * (RING - 1))) % RING);
      return {
        rings,
        start,
        check: offsets => offsets.map((o, i) => o === solution[i]),
        reveal: () => ({ offsets: [...solution], words: [...chosen] }),
      };
    }
  }
  throw new Error(`no unique puzzle for ${lang}:${day}`);
}
```

```js
// Persistencia en localStorage. Todo acceso tolera storage ausente o que lance (modo privado).
export const emptyStats = () => ({ played: 0, won: 0, streak: 0, maxStreak: 0, lastWinDay: null, dist: [0, 0, 0, 0, 0, 0] });

export function get(storage, key) {
  try {
    return JSON.parse(storage.getItem(key));
  } catch {
    return null;
  }
}

export function set(storage, key, value) {
  try {
    storage.setItem(key, JSON.stringify(value));
  } catch {}
}

// Partida de hoy en `lang`; si la guardada es de otro día se descarta, las estadísticas se conservan.
export function loadGame(storage, lang, day) {
  const saved = get(storage, `wordini:${lang}`);
  const stats = saved?.stats ?? emptyStats();
  if (saved?.day === day) return saved;
  return { day, offsets: null, attempts: [], tried: [], status: 'playing', stats };
}

export const saveGame = (storage, lang, game) => set(storage, `wordini:${lang}`, game);

export function recordResult(stats, day, won, nAttempts) {
  const s = { ...stats, dist: [...stats.dist], played: stats.played + 1 };
  if (!won) return { ...s, streak: 0 };
  s.won++;
  s.dist[nAttempts - 1]++;
  s.streak = stats.lastWinDay === day - 1 ? stats.streak + 1 : 1;
  s.maxStreak = Math.max(s.maxStreak, s.streak);
  s.lastWinDay = day;
  return s;
}
```

- [ ] **Paso 3: `js/fx.js`**

Los sonidos se sintetizan con Web Audio en estilo chiptune, sin archivos. El confetti se importa de forma dinámica: si jsDelivr no responde, solo falta el confetti.

```js
// Efectos: sonido chiptune sintetizado (sin archivos), vibración y confetti. Si algo falla, el juego sigue.
const calm = matchMedia('(prefers-reduced-motion: reduce)').matches;
const CONFETTI = 'https://cdn.jsdelivr.net/npm/canvas-confetti@1.9.4/+esm';
let ctx;

export let muted = false;
export const setMuted = m => (muted = m);

// Los navegadores solo dejan sonar audio creado o reanudado durante un gesto del usuario.
export function unlock() {
  if (muted) return;
  try {
    ctx ??= new AudioContext();
    if (ctx.state !== 'running') ctx.resume();
  } catch {}
}

function beep(freq, duration, type, delay = 0, volume = 0.06) {
  if (muted) return;
  try {
    ctx ??= new AudioContext();
    const t0 = ctx.currentTime + delay;
    const osc = ctx.createOscillator();
    const gain = ctx.createGain();
    osc.type = type;
    osc.frequency.setValueAtTime(freq, t0);
    gain.gain.setValueAtTime(volume, t0);
    gain.gain.exponentialRampToValueAtTime(0.0001, t0 + duration);
    osc.connect(gain).connect(ctx.destination);
    osc.start(t0);
    osc.stop(t0 + duration);
  } catch {}
}

export function tick() {
  beep(1800, 0.03, 'square', 0, 0.03);
  navigator.vibrate?.(10);
}

export function clack() {
  beep(140, 0.12, 'sawtooth', 0, 0.08);
  beep(90, 0.15, 'square', 0.04, 0.06);
}

export function win() {
  [523, 659, 784, 1047].forEach((f, k) => beep(f, 0.25, 'triangle', 0.15 + k * 0.09, 0.08));
  if (calm) return;
  import(CONFETTI)
    .then(m => m.default({ particleCount: 160, spread: 90, origin: { y: 0.6 }, colors: ['#00e5ff', '#ff2bd6', '#39ff88'] }))
    .catch(() => {});
}

export function lose() {
  [392, 330, 262].forEach((f, k) => beep(f, 0.3, 'sawtooth', 0.15 + k * 0.15, 0.05));
}
```

```js
import { createPuzzle, dayNumber, RING, COLS } from './puzzle.js';
import { shareText } from './share.js';
import { FLAGS, t } from './i18n.js';
import { get, set, loadGame, saveGame, recordResult } from './state.js';
import * as fx from './fx.js';

const MAX_ATTEMPTS = 6;
const calm = matchMedia('(prefers-reduced-motion: reduce)').matches;
const $ = sel => document.querySelector(sel);
const ringEl = i => $('#lock').children[i];

let storage;
try {
  storage = localStorage;
} catch {} // bloqueado: el juego funciona sin persistencia

let lang, puzzle, game;
let selected = 0;

const locked = i => game.attempts.some(a => a[i]);
const alreadyTried = () => game.tried.includes(game.offsets.join(''));

function pickLang() {
  const wanted = [new URLSearchParams(location.search).get('l'), get(storage, 'wordini:lang'), navigator.language?.slice(0, 2)];
  return wanted.find(l => Object.hasOwn(FLAGS, l ?? '')) ?? 'en';
}

async function start(newLang) {
  lang = newLang;
  set(storage, 'wordini:lang', lang);
  document.documentElement.lang = lang;
  $('#lang').value = lang;
  renderTexts();
  let words;
  try {
    words = await (await fetch(`words/${lang}.json`)).json();
  } catch {
    game = puzzle = undefined; // nunca guardar la partida de un idioma con la clave de otro
    $('#lock').replaceChildren();
    $('#message').textContent = t(lang, 'loadError');
    return;
  }
  if (lang !== newLang) return; // el jugador cambió de idioma mientras cargaba
  const day = dayNumber();
  puzzle = createPuzzle(lang, day, words);
  game = loadGame(storage, lang, day);
  game.offsets ??= [...puzzle.start];
  if (game.status === 'lost') game.offsets = puzzle.reveal().offsets;
  renderLock();
  renderStatus();
}

function renderTexts() {
  for (const el of document.querySelectorAll('[data-t]')) el.textContent = t(lang, el.dataset.t);
  for (const el of document.querySelectorAll('[data-label]')) {
    el.title = t(lang, el.dataset.label);
    el.setAttribute('aria-label', el.title);
  }
}

function renderLock() {
  $('#lock').replaceChildren(
    ...puzzle.rings.map((_, i) => {
      const ring = document.createElement('div');
      ring.className = 'ring';
      ring.tabIndex = 0;
      ring.style.setProperty('--i', i);
      ring.innerHTML =
        '<button class="up" tabindex="-1" aria-hidden="true">▲</button>' +
        '<div class="reel"><div class="strip"></div></div>' +
        '<button class="down" tabindex="-1" aria-hidden="true">▼</button>';
      ring.querySelector('.up').onclick = () => rotate(i, 1);
      ring.querySelector('.down').onclick = () => rotate(i, -1);
      ring.onfocus = () => (selected = i);
      dragToRotate(ring.querySelector('.reel'), i);
      return ring;
    }),
  );
  puzzle.rings.forEach((_, i) => renderRing(i, 0));
}

// Muestra 5 letras: 1 arriba, las 3 de la ventana y 1 abajo. dir anima el paso (+1 sube, -1 baja).
function renderRing(i, dir) {
  const ring = ringEl(i);
  const o = game.offsets[i];
  const letters = [-1, 0, 1, 2, 3].map(k => puzzle.rings[i][(o + k + RING) % RING]);
  const strip = ring.querySelector('.strip');
  strip.replaceChildren(...letters.map(c => Object.assign(document.createElement('div'), { className: 'cell', textContent: c })));
  ring.classList.toggle('locked', locked(i));
  ring.setAttribute('aria-label', letters.slice(1, 4).join(' '));
  if (dir && !calm) {
    strip.animate([{ transform: `translateY(${dir * 20}%)` }, { transform: 'none' }], { duration: 140, easing: 'cubic-bezier(.3,1.6,.5,1)' });
  }
}

function rotate(i, dir) {
  selected = i;
  if (game.status !== 'playing' || locked(i)) return;
  game.offsets[i] = (game.offsets[i] + dir + RING) % RING;
  renderRing(i, dir);
  fx.tick();
  renderStatus();
  saveGame(storage, lang, game);
}

// Cada vez que el arrastre recorre la altura de una letra, el anillo avanza un paso.
function dragToRotate(reel, i) {
  let y0 = null;
  reel.onpointerdown = e => {
    y0 = e.clientY;
    reel.setPointerCapture(e.pointerId);
    ringEl(i).focus({ preventScroll: true });
  };
  reel.onpointermove = e => {
    if (y0 === null) return;
    const cell = reel.offsetHeight / 5;
    while (y0 - e.clientY >= cell) {
      rotate(i, 1);
      y0 -= cell;
    }
    while (e.clientY - y0 >= cell) {
      rotate(i, -1);
      y0 += cell;
    }
  };
  reel.onpointerup = reel.onpointercancel = () => (y0 = null);
}

function open() {
  if (!game || game.status !== 'playing' || alreadyTried()) return;
  const result = puzzle.check(game.offsets);
  game.attempts.push(result);
  game.tried.push(game.offsets.join(''));
  fx.clack();
  if (result.every(Boolean)) finish(true);
  else if (game.attempts.length === MAX_ATTEMPTS) finish(false);
  saveGame(storage, lang, game);
  puzzle.rings.forEach((_, i) => renderRing(i, 0));
  renderStatus();
}

function finish(won) {
  game.status = won ? 'won' : 'lost';
  game.stats = recordResult(game.stats, game.day, won, game.attempts.length);
  if (won) fx.win();
  else {
    fx.lose();
    spinTo(puzzle.reveal().offsets);
  }
  setTimeout(showStats, 1500);
}

// Derrota: los anillos giran paso a paso hasta la solución (o saltan si se pidió menos movimiento).
async function spinTo(target) {
  while (game.offsets.some((o, i) => o !== target[i])) {
    game.offsets.forEach((o, i) => {
      if (o === target[i]) return;
      game.offsets[i] = (o + 1) % RING;
      renderRing(i, 1);
    });
    if (!calm) await new Promise(r => setTimeout(r, 90));
  }
}

function renderStatus() {
  const btn = $('#btn-open');
  btn.textContent = `${t(lang, 'open')} · ${MAX_ATTEMPTS - game.attempts.length}`;
  btn.disabled = game.status !== 'playing' || alreadyTried();
  $('#lock').classList.toggle('won', game.status === 'won');
  $('#lock').classList.toggle('lost', game.status === 'lost');
  $('#history').replaceChildren(
    ...game.attempts.map(a => {
      const li = document.createElement('li');
      li.setAttribute('aria-label', `${a.filter(Boolean).length}/${COLS}`);
      li.innerHTML = a.map(ok => `<span class="sq${ok ? ' ok' : ''}"></span>`).join('');
      return li;
    }),
  );
  const over = game.status !== 'playing';
  $('#message').textContent = over ? `${t(lang, game.status)} ${puzzle.reveal().words.join(' · ')}` : '';
}

function showStats() {
  if (!game) return;
  const s = game.stats;
  const cells = [[s.played, 'played'], [s.played ? Math.round((100 * s.won) / s.played) : 0, 'winPct'], [s.streak, 'streak'], [s.maxStreak, 'maxStreak']];
  $('#stats').innerHTML = cells.map(([n, key]) => `<div><b>${n}</b><small>${t(lang, key)}</small></div>`).join('');
  const max = Math.max(1, ...s.dist);
  const today = game.status === 'won' ? game.attempts.length - 1 : -1;
  $('#dist').innerHTML = s.dist
    .map((n, k) => `<div class="row"><span>${k + 1}</span><span class="bar${k === today ? ' today' : ''}" style="width:${(100 * n) / max}%">${n}</span></div>`)
    .join('');
  $('#btn-share').hidden = $('#next').hidden = game.status === 'playing';
  $('#dlg-stats').showModal();
}

async function share() {
  const url = `${location.origin}${location.pathname}?l=${lang}`;
  const text = shareText(lang, game.day + 1, game.attempts, game.status === 'won', url);
  if (navigator.share) {
    try {
      await navigator.share({ text });
      return;
    } catch (e) {
      if (e.name === 'AbortError') return;
    }
  }
  try {
    await navigator.clipboard.writeText(text);
    $('#btn-share').textContent = t(lang, 'copied');
    setTimeout(() => ($('#btn-share').textContent = t(lang, 'share')), 1500);
  } catch {
    prompt('', text); // sin portapapeles: que lo copie a mano
  }
}

function onKey(e) {
  if (!game || document.querySelector('dialog[open]') || e.target.tagName === 'SELECT') return;
  if (e.key === 'Enter' && e.target.tagName === 'BUTTON') return; // el botón ya recibe el click
  const actions = {
    ArrowLeft: () => ringEl((selected + COLS - 1) % COLS).focus(),
    ArrowRight: () => ringEl((selected + 1) % COLS).focus(),
    ArrowUp: () => rotate(selected, 1),
    ArrowDown: () => rotate(selected, -1),
    Enter: open,
  };
  if (!actions[e.key]) return;
  e.preventDefault();
  actions[e.key]();
}

function renderMute() {
  $('#btn-mute').textContent = fx.muted ? '🔇' : '🔊';
}

$('#lang').innerHTML = Object.entries(FLAGS).map(([l, flag]) => `<option value="${l}">${flag} ${l.toUpperCase()}</option>`).join('');
fx.setMuted(get(storage, 'wordini:muted') === true);
renderMute();
await start(pickLang());

$('#lang').onchange = e => start(e.target.value);
$('#btn-open').onclick = open;
$('#btn-help').onclick = () => $('#dlg-help').showModal();
$('#btn-stats').onclick = showStats;
$('#btn-share').onclick = share;
$('#btn-mute').onclick = () => {
  fx.setMuted(!fx.muted);
  set(storage, 'wordini:muted', fx.muted);
  renderMute();
};
document.addEventListener('keydown', onKey);
for (const ev of ['pointerdown', 'keydown']) document.addEventListener(ev, fx.unlock);
document.addEventListener('visibilitychange', () => {
  if (!document.hidden && game && dayNumber() !== game.day) start(lang); // pasó la medianoche con la pestaña abierta
});

if (!get(storage, 'wordini:help-seen')) {
  $('#dlg-help').showModal();
  set(storage, 'wordini:help-seen', true);
}
```
